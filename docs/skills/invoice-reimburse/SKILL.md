## 入口
用户发来一堆发票文件（PDF、图片、OFD），要生成一张报销单、按类别汇总、算总金额，或者问「这些票一共多少」时。

别拿错：只管“把票变成报销单”；只查重复和日期用 invoice-ledger-check，建档用 e-invoice-archive。

## 步骤
1. 先列清单：几张票、什么类型（增值税专票、普票、电子票、行程单、出租车票）、在哪个目录。
2. 每张票抽出：发票号码、开票日期、销售方、购买方、金额（不含税）、税额、价税合计。抽不全的标低置信度，并列出缺哪几个字段。
3. 校验：价税合计 = 金额 + 税额（容差 1 分）；发票号码 + 金额相同的按重复票处理，保留第一张。
4. 按类别归集（交通、住宿、餐饮、办公、其他），每类给小计，最后给总计。
5. 生成报销单一式两份：明细版（逐张列出）与汇总版（按类别），都带上「共几张、合计多少、税额多少」。
6. 输出文件写好路径，告诉用户在哪。

## 容易出错的地方
算式必须真算：先把「金额 + 税额」算出一个数，再拿这个数去比价税合计；不允许把表上的价税合计直接拄到等号右边当结果。反例：金额 200、税额 26、价税合计 300，200+26=226≠300，差 74，必须报为不符，写成「相符」就是错的。
- 发票图片模糊或拍照歪斜时字段会抽错，必须交叉核对金额与合计。
- 行程单的票价与税额口径和增值税发票不同，别混在一张表里直接加。
- 免税票税额为 0，不是抽取失败。
- 同一张票既有 PDF 又有截图，会重复计入。
- 报销单上的金额单位要统一到元并保留两位小数，按分算完再转换。

## 怎样算办成
- 每张票有结构化记录，能追回原文件；
- 汇总金额与逐张加起来一致；
- 报销单文件已生成并给出路径，打开就能交。

## 什么时候停下交给用户
- 要连发票查验平台、上传到报销系统或 OA 时，停下交给用户。
- 关键字段抽不出来又无法核对时，报出是哪张票，让用户补拍或补传。
- 金额合计达到需要审批或明显异常（单张过大、同一天多条同类）时，提示用户确认再继续。
