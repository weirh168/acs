## 入口
用户问风水:怎么看生气、没有龙脉怎么办、光影(采光/投影)影响、阴阳冷热刚柔、宾主布局、象法断事、化煞、水法、室内/楼盘/厂房/商铺选址布局、催丁催婚。
资料是《形气风水》讲义 24 讲(口语课),已按主题归并成分篇,照讲义原意说话。

1. 先定位:用 `skill_read` 读 `references/00-index.md`,按「第几讲 / 主题」找篇,再读那一份(大篇拆成 -1/-2)。
2. 按题分派:

   - 柔局与行业对应(什么行气出什么行业)、形峦派与理气派总览 → `references/02-xingqi.md`
   - 光影法:投影与影像、采光开门窗、七色光谱、商业与家居应用 → `references/03-guangying.md`
   - 阴阳:八卦阴阳、生死阴阳、冷热阴阳、老阴局与烂尾楼、刚柔与应人应事 → `references/04-yinyang-1.md`、`-2.md`

## 容易出错的地方
- 这是**形气派的口语课**,重「看形、看气、看光影」,不讲罗盘分金那套;别把三僚、金镖门的理气/分金条文搬进来。
- 讲义反复强调「风水是加分项,不能逆天改命」,断事别说成保证;涉及疾病、生死、婚姻结果时按讲义口径讲概率与倾向。
- 讲义里的分数(生气 300 分制)、行业对应(纺织、五金等)是作者经验体系,标明出自本讲义,不当普适定论。
- 讲义是语音转写稿,错别字与口语重复很多(如「水乡」多为「水向/水法」、「行气」=形气),理解意思后再答,别照抄病句。
- 讲次之间内容有重复与回头补充(前面说后面再讲),以主题篇为准,别把某讲的临时说法当定论。

## 怎样算办成
- 问题能落到具体讲次:给出「第 N 讲 + 结论 + 现场怎么验」;
- 问生气/选址时,能给出生气三要素(龙脉、藏风、堂局)的现场判断;
- 问布局/化煞时,能给出方位、形制与替代方案,而不是只背吉凶词。

## 什么时候停下交给用户
- 需要现场数据(平面图、门窗方位、周边高低、采光朝向、实拍照片)才能判断时,列出要拍什么、量什么;
- 涉及动土、装修开工、择日的具体日子,提示要按当地习俗与主家情况复核,不代下定论;
- 问到讲义没有的内容,直接说「讲义未讲」,不要编。
