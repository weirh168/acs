# 室内设计布局(第 2/2 部分)

来我们看一下，大房子就是大人，小房子就是小孩儿，大人牵小孩儿之下，那么我们大山呢，就是大人发出的余气呢，就是小山，就是小孩儿，所以大山发出余气的地方，那么就会人低洼，大房子发出小房子的这种就叫大人迁小孩儿的形象。以此类推，那么我们比如说前面做一个别墅，前面我们就要加一个花坛，那就像大人牵小孩的一样，因为别墅为大人，那么花坛呢，就是小孩儿，以此类推。
所以呢，我们别墅那边儿，那如果没有小孩儿，我们该怎么办?可以在别墅的大门口做一个花坛，花坛里呢，带有这种小孩儿的图片，因为别墅就是大人嘛，花坛就是小孩儿，那么花坛呢，在风水里呢，代表关心，代表紫气的，代表语气。器也是一样的，炊丁之法，那么在别墅的地方就可以前面建一个圆润的花坛。
催丁法
别墅大门前面建花坛止气，
选有大房连小房的商品房
通过上面的，大家自己看这些图片就知道其中的原理了，一种就是在别墅那边儿的大门口前面建一个花坛。这种呢，是锤定的方法，第二种呢，就是我们选这种商品房，那种商品房呢，大房子代表着大人啊，前面发出语气就在小孩儿，所以我们就选这种房子。那如果我们没有了，我们可以租这种房子住，这种呢，能够促进我们的催眠，能够促进呢，早日怀上小孩儿，这就是我们风水的方法，当然呢，更好的方法呢，还是要听医生的，该吃药吃药，该保健该保健，该锻炼则锻炼。这些是要循环进渐的，风水不是万能的，所以只有中医与风水共同配合才能够解决问题。
催丁常用的方法有
1、气口催丁
找准气口的位置，选用其特殊的月日进行催丁。
2、日课催丁
例如入新居、安灶、安床等方式进行催丁。
