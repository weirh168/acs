## 入口
用户问风水:寻龙点穴、看地断吉凶、阴阳宅形法、立向分金、八宅布局、玄空飞星、罗盘二十四山、择日配合八字。
资料是《金镖门阴阳宅形法风水概论》原文,按原书七个部分切开,照原文立场说话。

## 步骤
1. 先定位:用 `skill_read` 读 `references/00-index.md`,按「部分」找篇,再读那一份。
2. 按题分派:
   - 风水是什么、气与阴阳、天人感应、龙穴与理气日课的关系、师承源流 → `references/01-preface.md`
   - 理气:阴阳五行、干支、龙水向配合、生克 → `references/02-liqi.md`
   - 八宅:东西四宅、九星翻卦、门主灶、床位 → `references/03-bazhai.md`
   - 立向、分金、兼向、开门楼 → `references/04-lixiang.md`
   - 玄空飞星:元运、下卦、旺山旺向、上山下水、双星会向/会坐 → `references/05-xuankong.md`
   - 收山出煞诀、天盘双山、人盘双山、龙身三合、向上三合、坐山三合、分金三合 → `references/06-shoushan.md`
   - 罗盘二十四山逐山:坐某山向某向、何方可来水、何方可去水、犯什么煞 → `references/07-luopan.md`
3. 答题格式:先给结论,再写依据(标到「第几部分 + 哪一山向」,如「第八部分 子山午向」),原文有断语的引原句,最后给现场检查清单(量什么、看什么、怎么判)。
4. 需要具体山向时,先确认用户的坐向度数或山向名,再去 07 那份里查那一条;不要自己概括其他山向。

## 容易出错的地方
- 这是**金镖门形法**一派:主张「先形峦、后理气」,先弃罗盘静心寻龙点穴,再谈理气;别把三僚、玄空其他支派的说法混进来。
- 门内有「配合八字用神选山向门楼、再配元运日课」的单传做法,原文提到但没给完整推演表;用户要具体命例时,说明原书只给了原则,别硬凑。
- 原文例子多带真实人名家墓(如赖恩爵祖坟),引用时注明是原书案例,不当成通用结论。
- 罗盘部分讲的是**逐山固定条文**,不同山向吉凶不同,别把一山的条文套到另一山。
- 原书是扫描整理稿,个别字有错讹(如「口」多为「水口」之省),读不通按上下文校正,别照抄错字。

## 怎样算办成
- 问题能落到具体部分:给出「部分 + 结论 + 现场怎么验」;
- 问具体山向时,能准确引到 07 里该山向的来水去水与所忌;
- 问八宅/玄空时,能给出对应的翻卦或飞星步骤,而不是只给吉凶词。

## 什么时候停下交给用户
- 需要现场数据(实测坐向度数、来去水方位、周围砂峰高低、房屋平面图)才能判断时,列出要测什么、怎么测;
- 涉及择日、下葬、动土的具体日子,提示必须由先生按当地历书与主家八字复核,不代下定论;
- 问到原书没有的内容,直接说「原书未载」,不要编。
