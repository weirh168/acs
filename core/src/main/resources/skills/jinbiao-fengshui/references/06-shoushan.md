# 收山出煞与三合

第七部分：收山出煞诀 + 天盘/人盘双山、龙身三合、向上三合、坐山三合、分金三合

第七部分：金镖门收山出煞诀
任何事物，都是矛盾统一的，也都离不开阴阳二气的运行，易经云：一
阴一阳谓之道，阴阳不测谓之神。阴一片，阳一片，阳气左旋，阴气右旋十天干生旺死绝表：
口诀是：
甲庚壬丙四阳星，左转是真宗乙辛丁癸四阴星，右路来相逢识得阴阳二路行，代代人富贵不识阴阳二路行，万丈火坑深左右兼加颠倒颠，阴阳看兼针山主人丁水主财，顺逆好安排先天罗经十二支，莫言正龙空穿山透地是真诀，休与浪人说
师言：时时刻刻不忘穿山透地，即念念不忘，必有回响。
三合局：
申子辰三合水局，寅午戌三合火局亥卯未三合木局， 巳酉丑三合金局原则是：有局先论局，无局方论用
因为局为气势，如八字中的三合局，就是一股强烈的气势，我们一定要考虑。大家可以到实际中验证，真乃百发百中，例无虚发之宝。
双山五行：经云：二十四山双双起，少有时师通此义
一、天盘双山：
壬子，癸丑， 艮寅， 甲卯，乙辰，巽巳，丙午，丁未，庚申，庚酉，辛戌，乾亥
二、人盘双山：
子癸，丑艮，寅甲，卯乙，辰巽， 巳丙，午丁，未坤， 申庚，酉辛，戌乾，亥壬
今人多宗地盘，弃人盘天盘于不顾，不知出于何种原因，三盘来源于天文，缺一不可，金镖门祖师，都是三盘兼顾，贯穿而用。最后虽为三盘，又统而一盘。
山主人丁水主财，左右兼加，则阴可变阳，阳可为阴，阴阳二宅，侧重不同，坐以收山， 向以纳水。
穿山透地与坐穴，即分金妙用穿山为未来之气，坐穴为已进之气，透地为即进之气，须三盘兼用，有以透地为主，有以坐穴为主。经云：先识穿山虎，方行透地龙，浑天开宝镜，金水月相逢。
分金在三合之外而用三合，与三合实为一理。局好比是国家，分金代表个人。首先要符合国家之势，然后才言个人富贵。有国才有家，才有保证，虽然战乱时也有当官富人，终究提心吊胆，现在国家繁荣时，亦有穷人，最少也是丰衣足食，不愁一 日三餐。
最好局与分金皆合，借国家之势，发挥自身最大的才能，取得最大的收获。阴宅，分金重于局，局不合，以分金为主，阳宅，以局为重，元运为重，分金次之。阴阳二宅，最好能两者皆合，方为全美。
阴宅壬山丙向，三合局坐山坤壬乙， 向上艮丙辛，故左水出辛戌，右水出乙辰， 皆为局合，分金而言，左水来，走丁未，出辛戌亦合，右水来， 出乙辰丑艮亦合。有是局，则壬丙正向皆合。如壬兼子， 向丙兼午，局分申子辰与寅午戌。左水来，出辛戌，合局合分金，右水来，亦合局合分金。两者亦全合。
如壬兼亥，向丙兼巳，局为亥卯未，巳酉丑，穿山癸亥水，透地甲子金，左水来， 出未，局合，分金不合，阳宅亦发，阴宅有所不利，如出丙，为金局沐浴大利，如龙从艮来，阴宅则毫无生发，灾祸不断。右水来出乙辰，局不合，分金亦不合，阴阳宅俱无生发。如龙从艮来，又可转凶为吉。阴宅大利，阳宅有所偏房，富贵不能两全。所以古人言，富贵出在龙身上，诚不欺人。
七曜诗：养生贪狼位，沐浴冠带文，临官帝旺武，逢衰是巨门，病死廉贞位，绝胎是禄存，大墓属破军。

四大局：
辛壬会聚辰，乙丙交趋戌，金羊收癸甲，斗牛纳庚丁
即：水出乙辰巽巳丙午方为水局，出丁未坤申庚酉为木局，出辛戌乾亥壬子为火局， 出癸丑艮寅甲卯为金局。
其中又分为水口一盘， 向上一盘，坐山一盘，龙上一盘，分金一盘。
阴宅，先分清大局水口流往何方，如水出东南乙辰巽巳丙午方，即为水局，辛壬会聚辰，如左水倒右，是辛龙壬水，辛龙长生在子，旺在申，墓在辰，而壬水，是长生在申，旺在子，墓在辰。先看龙从何方起祖，何方入首起顶。何方下脉，长生冠带临官龙为吉，余则为凶，又看水从何方入局，如坤申乾亥壬子癸丑为吉，余则为凶。此即入山观水口之意，即看大局之水 口，同时看定龙身起祖，入首，起顶之方
二、龙身三合：
看一地之来龙从何方来，用罗经测定，如是辛戌乾亥壬子方来龙，假如龙身左旋，则水为右旋，此时水必归乙辰巽巳丙午，是水局龙，辛壬会聚辰，壬龙辛水，假如龙身右旋，则水为左旋，此时水必归于丁未坤申庚酉，则变为木局龙，金羊收癸甲之灵，是癸龙甲水，癸龙生卯旺子墓未， 甲水生亥旺卯墓未，看龙从何方起祖，剥换至何方入首起顶下脉，水归合处
三、向上三合：
向上三合，即双山五形，如丙午向，丙午为火，长生在艮寅，旺在丙午，墓在辛戌，宜左水倒右，收左边艮寅长生，乙辰冠带，巽巳临官水倒右出丁未或是辛戌方，右水倒左出向上丙方或是左边甲方，为借局而消。因丁未方为木局之库，火局之衰， 甲方为火局之沐浴，丙方为水局之胎，俱为合法。
四、坐山三合：八干四维辅支位，子母公孙从此推
壬兼子，以子为主，子是申子辰三合，壬兼亥，以亥为主，亥是亥卯未三合。
五、分金三合：
分金三合，即为三针四线的应用，如子山兼壬一九分金，七十二龙是戊子分金，戊子属火，喜左水倒右，从未坤方流出为合局，如透地得庚子土龙贯穴，又喜右水倒左出乙辰方合，经云： 富贵出在龙身上。而百二十分金，又为旺相孤虚，补龙扶山之用，如龙强，不需要分金补助，故可坐虚位，如龙弱，必要分金补助，是为补龙扶山相主，又不可与年命相克。此虽言日课，又言分金。
实际应用中，这三盘是穿插应用，不分彼此。大龙定局， 内水消，特别是近身小水，尤关祸福，慎之慎之。
