# 八宅

第三部分：八宅(东西四宅、九星、门主灶)

第三部分：八宅
很多人认为八宅没用，但是八宅一直都有在使用，只是有其特定使用条件，这次我们在课程里面做一个使用经验方面的介绍，首先我们要知道什么是八宅理论。在古代一般祖宅之类，居住时间长，必须考虑八宅，而现在厂房店铺之类不用八宅，因为八宅时效太长，效果不明显，不如用玄空，乘时开门，收一元之旺，效果立竿见影。
八宅，就是坊间大家所说的东四命，西四命，有以年命来论，东四命住东四宅，西四命住西四宅，有以坐山来论，东四宅开东四门，西四宅开西四门，也有以门来论，东四门要按东四宅的床，西四宅要按西四宅的门。也有以高楼来论，东四方有高楼，要开东四门，西四方有高楼，要开西四门等等。金镖门认为他们的说法都对，关键是看力量，记住，谁有力量，就用谁，这叫大势所趋。我们任何时候，不能去违反这个势，只能因势利导。
所以如果住宅周围的巽方有一栋高楼高达十几层，周边没有高楼了，那么这个高楼就是这栋房子的唯一用神，那此时我们就要以这栋高楼为用神来考虑。有院落的时候，此楼与院门需要东西相同。巽方高楼， 门开坎，震，巽，离方，如高楼在坤， 门 口开坤，兑，乾， 艮之方。 以此类推。
如果周围没有特别的用神，而坐山反而势重，此时我们又要以坐山来看，东四宅开东四门，西四宅开西四门。
或者来路在东四方，坐东四宅，来路在西四方，坐西四宅。
所以，一切看力量。 同时，还要兼顾年命，东四命，开东四门，东四卦做主。阳宅内灶的方位，压年命凶方，向吉方，现在煤气灶开关不能坐向论，所以是没有向，只论坐，最好在年命之吉方， 同时压凶方。
八宅理论，在北方相对平坦的地方，周围没有明显的高低，更没有明显的来去水路。各家各户都有院落，此时可以考虑八宅的吉凶。让其主房与大门，卦位相同。如不同，需要主房为主，外面宾位来辅助，如在向上，又需要与门相配。南方的话，一般用在厂区内部，因为厂区内部会相对平坦，没有地势落差，如果外面有落差，那么厂区周围一定要用实心围墙隔开，空心效果减半，然后看门与自 己本身建筑物的关系，同时参看外部建筑物的高低，站在办公楼门前，看大门在何方，周围最高点在何方，来路在何方，一一看定。
如围墙门在东南巽方，本身建筑物在北方，外围离方有高楼，即以门起伏位，离为天医，坎为生气，俱在吉方。那么此宅大吉。如高楼在西南方，即五鬼方起高楼，如果来路又从西南方来，是五鬼重叠，凶上加凶。此时又需门开坤方以从高楼之势。金镖门的经验是：靠近主楼后面的高楼，用主房起伏， 向上的楼房，用门起伏。
如果是周围地势平坦，边上也没有明显的高楼，或者周围房子高低整齐，
而来路口集中，此时可以以路与房子来论。以道路来论的时候，即以道路的中心点或者着力点，来看房子在道路的何方。所谓的中心点或者着力点，就是周围的动点，动点一般位于房子周围的十字路口，三岔路口处。以此动点来看房子位于动点的何方，如果是在动点的南方，那么房子与这个动点就是坎离互为延年大吉，如果房子是位于此动点的巽方，那么房子与这个动点就是乾巽互为祸害不吉，会出现疾病离婚等不利。如果这个动点与房子的连线是艮坤， 艮坤互为生气大吉，如果动点与房子的连线是震兑，震兑互为绝命，那么此宅就是大凶，会出人命官司破财等。
如果房子的周围是直直的马路，没有三叉十字丁字等路 口，也没有明显的高楼，此时就应该以大门来定，看其大门与来路的关系，次看与主房之间的关系，是吉是凶了。
上面说的都是房子的外局，富贵程度的大小取决于外局，而内局吗，也同样重要，甚至人事上的吉凶情况， 内局还大于外局，如人丁的顺遂与否，身体疾病，外局财富的收纳情况，都与内局相关。比如外局明堂漂亮，朝山有情，本应是丁财两旺的格局，如内局为凶， 同样会损丁破财，且会发凶。好比外局有一个亿的钱等着你拿，可惜你身体不行，拿了五十万就吃不消了。金镖门内局有一套自己的方法，与市面上不同的是，先求宅命的五行，然后再论门主灶的吉凶情况，等有机会我们再来一起研究。
