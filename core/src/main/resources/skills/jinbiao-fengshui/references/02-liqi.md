# 金镖门理气

第二部分：理气(阴阳、五行、干支、龙水向配)

第二部分：金镖门理气
金镖门理气有五大类，为何会有这么多的理气，不像其他门派，一个理论就可以吃遍天呢？你们研究八字的都清楚，刚开始，我们学格局，什么正官格，印绶格啊，学到一定程度，发现有些八字用格局断不准，这个时候我们改用旺衰，还要加上调侯等等。
而风水比八字还要复杂，我们国家南北东西地域差异很大，有些方法适用于山区，有些适用于平原，有些理论只用于阳宅，有些理论只能用在阴宅，所以也就会产生很多派别出来，或者是我们只有了解清楚这些理论，知道他们的使用条件，才能因势利导，解决问题。
如山区，地气盛而天气浮，所以首重三合局，元运为辅，从形理言之，形为体，理气为用，同时理气上又分为三合三元，此时以三合为体，三元为用。历代名墓，个个都是吻合三合的。因为这是体，然后配合元运，可以寅葬卯发，但是三合本身又分为多个派别，并不是一个地理五诀而已，此又不可不知。关于三合的论法，后面有较为详细的论述。平洋地区，水势浩荡，天气盛而地气虚，此时又当以元运为主，地气为辅，合两盘而统之，方为全美。现在一些人，学了三合的，说元运不行，反之，学三元的，又否定三合，挂一漏万，不可轻率。
1.以年命纳音为主，配合八卦方位

用法：类同于八字，喜正官，正印，食神，偏财，比肩为吉，而以七杀，伤官，劫财为凶，偏印正财吉凶参半，正财主辛苦得小财，偏印为偏贵人。仕途中人喜正官，孩子喜食神，生意人喜偏财。
如丙申年出生，不论男女，丙申纳音为火，丙为阳，故为阳火，喜阳宅开门安床于巽方，巽为阴木，木生火为正印，主招贵人， 艮方阳土，为食神吉，乾方偏财利财，坎方为水，因坎卦没有阴阳，故须以坎卦壬子癸三山来定，壬为阳水，子癸为阴水，开门安床于壬方，犯七煞为凶，于子癸方，正官为吉，离卦丙方为阳火，比肩为吉，午丁阴火劫财为凶。坤方阴土伤官为凶，兑卦正财，卯方偏印，吉凶参半。
如壬子年出生，不论男女，壬子纳音属木，壬为阳，故为阳木。喜阳宅开门安床于坎卦，坎为水为印绶，喜艮为阳土偏财吉，喜兑方正官利名吉，喜离卦丙方食神吉，忌离卦午丁伤官，忌乾卦七煞，忌巽方劫财。以此类推
如果高楼选择楼层，宅主年命戊午，戊午为阳火，生意人求财，喜选择四九金层， 四为阴金正财辛苦得小财，九为偏财，主意外之财，横财。如果是当官的，喜六楼阴水为正官，忌一楼阳水七煞。如果刚好选择在一楼阳水七煞位，最好开门在震巽木方，化煞生印，或者开门在艮方，食神制煞方可，化煞生印或食神制煞，多主武职。
有人问：我一朋友壬申年的，请帮我看看，目前我住在五楼，门开子方。
壬申年纳音属金，壬为阳，所以是阳金，五楼为阳土，为偏印。偏印主招贵人，但是这个贵人要你主动提出来，另外就是很多时候，往往是表面同意，实际还要你来破费，因为偏印嘛，不如正印如母亲一般的无偿付出，另外还有一层含义是，你所找的贵人本身并不是直接负责某件事情，他也需要另外再托人。

门主财， 因为门为纳气 口，为虚的， 山主人丁水主财，大家都知道吧，门在坎卦，命是阳金，金生水，是食神，食神泄秀生财，好啊，而且壬子方，与年命申金三合，所以住进来之后，财运不错，但是床在坎卦的子癸方，是阴水伤官，说明庚子年会有不舒服。
来人说：对的，是下半年快过年的时候
这就对了，这是流年对应流月，子方对应子年，子癸丑方对应下半年时间。然后我建议移到坤方去，坤为阴土是你的正印，印绶生身，你是壬申的，坤方也是申金得长生方，移到这里后，各方面都很顺利很多，同时还会遇到贵人。
之后半年反馈：谢谢师父，现在确实挺顺利的，各方面都不错。
这是金镖门的第一个理论，实用性很广泛。因人而异，我们在现实中，看到某些人住某房很好，换了一个人就出事，或者某些店铺原来生意不行，换个人反而生意兴隆。有年命，有纳音，都会起作用，如果你属兔，门开正西，虽然合了纳音，也不利， 因为正西酉金克卯，年命受克， 当然不利， 同时，八卦分为二十四山，如东方甲卯乙三山，68 年戊申年出生，戊申为阳土，东方为阳木，七杀最凶，此时有两个方法化解：
1.在南方安床，使其木生火，火生土化解，而南方有丙午丁三山，不可在丙山，因为丙为阳火克申金，亦为七杀不利，主有官非是非。最好在午丁方，为年命的正官。
2.东方甲卯乙三山，最好是开在甲方， 因甲为年命申金得偏财，主轻松愉快，不要在卯乙方的正财，主劳心劳力且财小。其余以此类推。还有些情况是某些地方，不论何人居住也不利，这是由于外局实在糟糕，且理气驳杂，本身就是凶宅， 当然是谁住都不吉，只是凶的程度会因人而异。
