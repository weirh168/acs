# 玄空飞星

第五部分：玄空飞星(元运、下卦、旺山旺向)

第五部分：金镖门的玄空飞星
说到三元，不得不提玄空飞星这一段，因为这实在是太深入人心了，现在特别是自学风水的这一块，没有不学玄空飞星的
金镖门的玄空飞星分为山龙与水龙两部分， 山龙是依据来龙入首起星盘，没有入首数据，不要轻易下结论，后天盘的挨星，金镖门只适用于水龙，且不同于沈氏飞星，其盘有 81 局之变化，阳宅方面，先求宅命为体，然后飞星为用。如宅命为木，则五黄二黑八白为土为财，武曲破军为官杀，四绿为劫财，三碧为比肩，然后看身强身浅，强喜克制，弱喜生扶，类同于八字。
这里先谈一下山龙，只有收到先天龙气，才能配合立向。另外关于北斗七星打劫局与城门诀的运用，一定要知道来龙入首的数据，没有来龙入首，是没有所谓的打劫与城门诀的，因为打劫与城门，都与先天龙气有关。拿个比喻来说，龙和水是一对阴阳，也可以叫做一对夫妇，龙是男的，水是女的，而这个向呢，就是媒婆。一般情况，我们都是通过媒婆的介绍，男女双方才在一起。古代叫做父母之命，媒妁之言。而城门呢，是女方有很多家产，带着嫁妆过来，你用这个嫁妆，就可以一辈子不用干活了。那么打劫呢，打劫，只有强盗才会打劫，是指我只要看中这个女的，管它三七二十一，把她抢过来在说。所以打劫，是很粗暴的。但是要男的非常有能力，才会打劫成功，老百姓还没打劫，就会被抓起来了。在风水上，龙脉的力量最大，所以不知道来龙入首，就无从谈起北斗打劫与城门诀两个大法。
那什么是先天呢？先天就好比我们只在母体中还没有出世的时候，等出世了，我们看他有没有出息，我们去找父亲的基因如何？在风水上，就是真龙之气。一般的玄空盘，都是以运星入中宫，如现在八运， 以八入中宫顺飞八方，然后开山立向，用山向两星来挨周围的山水情况，是不是得运，得运就发，不得运山水漂亮，平平，碰到凶星发凶等等。这就是所谓的后天。那先天呢，它是倒着来的，如现在八运，西北方入首，此时我们不以八入中来飞布八方，而要以二入中来逆飞，逆飞到西北是一，然后这个一就是先天的龙气，那我们格龙的时候，还要确定西北方戌乾亥三山中的哪一山，确定好先天的龙气，我们才能依据这个龙气，进行三般卦的配置。此即无极子传蒋公的乾入坎诀。因八运是艮卦管事， 艮的先天在乾，与后天巽卦形成山泽通气，用此先天之艮，来交先天之兑，即是艮入巽也。先天用兑不用巽，先天论倒排父母，后天论星气流行。故龙用二而不用八，即此义也。
然后依后天所立之向，再来论来去之水，特别是水口的位置，这也是经文中所讲的“龙要合向， 向合水，水合三吉位 ”的真正核心点。
这也是我们金镖门不同于市面上的飞星之法，是我们金镖门的特色。
而水龙的用法，即是后天挨星盘，也就是现在大家所学的章氏飞星的部分。
在阳宅上，如果不论宅命，则经常与八宅同而用之，金镖门先师认为，八宅为体，飞星为用。因八宅效应相对较慢，需要一纪左右才效果明显，而飞星则相对较快，对于现在高节奏的时代而言，飞星亦可救贫于当下，且高楼的应用，飞星比八宅更适合，所以我们也谈一下金镖门对于飞星的应用。
有人问我，我这边有一个坟墓，立的是亥壬缝针，请问这样要如何来看？我说，坟墓首先应该知道是什么来龙，什么去水，你了解吗？他说不了解，好像水流前面，后面是山。我说：如果按照你的说法，亥龙巳口，立亥壬缝针的时候，在八运可以大发，就是 2004 年以后做的这个坟墓可以大发。他合了北斗打劫局与城门诀两个大法。葬下即发。而且是横发。如果不是缝针，那么它只是合了其中一法， 当然，有一法能合，即是有福。
他说对啊，师父，这个老板我认识的，他这个坟墓之前是九六年做的，那时候父亲先去世，葬下平平过，也是缝针，没有发，也没有败，开个小工厂加工做外贸生意，到 2008 年母亲去世，合葬在一起，也没有请过风水先生。结果这个老板从葬下这一年开始发财，2008 年那时候人家是经济危机，他反而风生水起，每天利润几十万，到现在已经是几十亿的大老板了。
这种情况说明此人有福气，本身八字就会发财，然后才是阴宅的配合。缝针的情况， 比较特殊。经文中言：双山双向水零神，富贵永无休，说的是缝针的情况,金镖门把正针作为正山正向，缝针作为双山双向，说到底，缝针，正针，只是根据山水形峦的具体情况而立，并不存在缝针不利的情况。只要是符合周围形峦，该缝就缝，该正就正，如果不符合自然的山水，正针，兼针，缝针，也就是下卦，替卦一样会出事。
一般市面上的玄空，特别是沈氏玄空的这一脉，都是一种后天的的运用，没有考虑到先天。
所以：起星即替卦或者是下卦的目的不外乎两种：配合天然的山水形势，并非下卦为吉，替卦或者逢针为凶。
