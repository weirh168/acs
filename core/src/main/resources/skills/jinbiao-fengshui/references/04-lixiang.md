# 金镖门立向

第四部分：立向与分金

第四部分：金镖门立向
现在市面上用玄空的人很多，但是大家基本都只是认为，收到旺星见了水就吉，收到衰星见了水，见了山就会凶。但是实际当中，很多房子收到旺星固然是吉，但是也有很多的房子，收到衰星也是大吉，这是为何呢？
金镖门的玄空不同于市面上的，一白贪狼，二黑巨门，三碧禄存，四绿文曲，五黄廉贞，六白武曲，七赤破军，八白左辅，九紫右弼这九个星辰，我们是都可以拿来应用的。并不会说这个运要收什么星才可以，很多时候，收到五黄，反而大发，这种局，我们称之为五鬼运财局。
而且，有龙的时候，我们一定要论龙，无龙的时候，我们才论局，龙是龙，局是局，概念不同。
经云：要向真龙观出脉，不从砂水断灾祥。
安坟立宅要合龙，不须拟对好奇峰。
说白了，就是依龙立向。
何龙立何向，这是定的，然后再根据元运的配合，此龙此向在何运最适合。龙是体， 向是用，龙是体，运为用。不得运，得龙，乘时而发，得龙得运，寅葬卯发。
无龙的时候，或者来龙不明显时，我们再考虑弃龙就局。
金镖门的玄空分为两大类，一是依据周围山水环境来立向，一是根据元运来立向，两者互为体用，有一定的山水，就有一定的立向规则，然后这个立向，在什么运来使用最佳。
以下立向规则请记牢
经文说： 甲庚壬丙俱属阳，顺推五行祥乙辛丁癸俱属阴，逆推论五行辰戌丑未扣金龙，动的永不穷乾坤艮巽天然穴，水来是真龙
这几句话的含义是告诉我们，如果是左水倒右，就是住宅或者坟墓前的水流是从左流到右边的，此时我们最好立甲庚丙壬向，如果是从右边流到左边的，也叫右水倒左，此时我们最好立乙辛丁癸向，如果水流是左右两水合夹从前面流出去，又称之为顺水，此时我们最好立辰戌丑未向。如果水是从当面流来，也叫逆水朝，此时我们最好立乾坤艮巽向。
阳宅，最怕去水。最喜来水。
正向少，兼加多，所以很多时候，反而须用兼加五行来论
所谓兼加五行，就是根据形峦的实际情况，如右水倒左，前面山水的自然条件，只有甲庚丙壬向可以立时，此时就要用兼加五行， 甲为阳，兼左从左，兼右从右，如右水倒左，立甲兼寅向就可以了。同理，如果是左水倒右，而向只有乙辛丁癸之向可以立，此时可以兼辰戌丑未
图中是左水倒右，宜甲庚壬丙向，或甲庚壬丙兼子午卯酉，或者是子午卯酉兼乙辛丁癸，又或者是乙辛丁癸兼辰戌丑未，不可乙辛丁癸兼子午卯酉，子午卯酉兼甲庚壬丙， 甲庚壬丙兼寅申巳亥，否则大地小发，且房份不均，甚至会绝房。
毛主席的曾祖周老孺人墓，是在龙头山上，丁山癸向兼午子，左水倒右从艮方消水。此向为忌，不过据说刚开始是兼丑未的，后来由于蒋介石挖坟，族人为了保护，把碑埋入土中，后来重立才变成这个向的。
此时是右水倒左，宜立乙辛丁癸正向，或乙辛丁癸兼子午卯酉，或子午卯酉兼甲庚壬丙， 甲庚壬丙兼寅申巳亥，不可子午卯酉兼乙辛丁癸，又或者是甲庚壬丙兼子午卯酉向
三僚刘若谷做的刘氏宗祠，立的是壬山丙向正针，网传是壬丙兼子午实际为错误。正向，用坤壬乙诀出乙方，为合局。
上图是两水合夹从当面去水，此时应立辰戌丑未，乙辛丁癸向或者是乾坤艮巽兼辰戌丑未向，又或者是立乙辛丁癸兼辰戌丑未之向。
浙江开化的钱王祖墓，立的是丑山未向正向，水从当面而出
此图是当面来水，宜立寅申巳亥向兼乾坤艮巽，或者乾坤艮巽正向，又或者是乙辛丁癸， 甲庚壬丙向兼子午卯酉。

此图当面来水，宜立乾坤艮巽兼寅申巳亥向，辰戌丑未向，又或者是寅申 巳亥正向。
杨公在流坑的飞蛾地与斗牛地，都是当面逆水朝，两者立的都是壬山丙向兼亥巳，属于正针范围。
以上是依形立向，然后才是配合理气。所有的形势，都有固定的山向，这是形理的高度统一。
