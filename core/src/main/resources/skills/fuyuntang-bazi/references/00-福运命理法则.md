```

  ↓

  ↓

  ↓
第九层：宫位定领域（年/月/日/时 → 哪个领域有事）
```

## 三、九大法则详解

### 1. 立极法则
| 根类型 | 地支 | 力度 | 含义 |
|--------|------|:--:|------|
| 强根 | 寅卯巳午申酉亥子 | ★★★ | 站得稳 |
| 余气根 | 辰戌丑未 | ★ | 勉强站稳 |
| 藏干根 | 地支所藏 | ☆ | 暗中有人帮 |
| 无根 | — | — | 浮萍漂泊 |

### 2. 体用法则
- 体 = 日主 + 比劫 + 印（自己的队伍）
- 用 = 食伤 + 财 + 官杀（外部的目标）

### 3. 做功法则
| 方式 | 条件 | 层次 |
|------|------|:--:|
| 食伤生财 | 食伤→财 | ★★★★ |
| 食伤制杀 | 食伤→七杀 | ★★★★ |
| 比劫制财 | 比劫→财 | ★★ |
| 杀印相生 | 杀→印→身 | ★★★★ |

### 4. 根基法则
- 根在年柱 → 祖上有靠
- 根在日柱 → 自己有底气
- 根在时柱 → 晚运有靠

### 5. 位置法则
| 宫位 | 被冲 | 被合 | 被刑/伏吟 |
|------|------|------|----------|
| 年柱 | 祖业变动 | 祖上有缘 | — |
| 月柱 | 换工作/搬家 | 工作稳定 | 事业停滞 |
| 日柱 | 感情变动 | 缘分到来 | 自我纠结 |
| 时柱 | 子女远行 | 子女缘好 | 晚年烦扰 |

### 6. 正局反局法则
- 正局 = 做功方向与日主意向一致
- 反局 = 做功方向与日主意向矛盾
- 暗局 = 正局中的内在消耗（自刑/混杂）

### 7. 应期法则
```
冲 > 合 > 刑 > 害 > 透干（优先级递减）
日柱 > 月柱 > 时柱 > 年柱（宫位优先级）
忌神被引动 > 喜神被引动（喜忌优先级）
```

### 8. 财官法则
| 身财关系 | 条件 | 含义 |
|---------|------|------|
| 身强财旺 | 能扛 | 发财能守 |
| 身强财弱 | 待运 | 大运一来就发 |
| 身弱财旺 | 扛不动 | 穷汉守金山 |
| 身弱财弱 | 平淡 | 小日子踏实 |

### 9. 宫位应事法则
```
流年地支=某柱地支 → 该宫位被引动 → 该领域有变
流年合某柱 → 合作/缘分
流年冲某柱 → 变动/冲突
```

## 八、叙事表达规范

### 三套输出模板🔒

**A. 一生分析** → 定调→三层结构→人群位置→未来走向
**B. 婚姻分析** → 正妻定位→感情模式→她承受的消耗→未来走向
**C. 性格分析** → 定调→三层结构→人群位置→优缺点→后来变化

### 五条叙事技巧

1. **隐喻贯通** — 一个核心隐喻贯穿全文（三辰之间的墙/橡皮筋/没有"温柔表达"功能）
2. **对比张力** — "他以为vs她需要"的对照结构（他以为给了就是爱了——工资卡=我爱你 vs 她要的是一句你今天累不累）
3. **情感翻译公式** — 十神数据→行为描述→内心动机→对方感受（偏财透干→工资卡=我爱你→但她要的是陪伴）
4. **时间累积感** — "不是一天…是日复一日…"（不是一天拉开的——是日复一日的"算了不说了"堆出来的墙）
5. **收尾留白** — 不总结，留一句有重量的话（如果能来早一点，会更好）

- [ ] 有贯穿隐喻
- [ ] 四级翻译完成
- [ ] 收尾留白
