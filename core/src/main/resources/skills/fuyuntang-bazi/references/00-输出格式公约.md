# 命理分析输出格式公约

> 每次命理分析自动载入。

---

## 核心规则

1. 推理用 pro 深度，一步不跳
2. 输出用文学化叙事，不列推演链，不说五行公式
3. 排盘盒用 ``` 代码块
4. 正文禁止使用 `**` `__` 加粗符号
5. 禁止使用表格格式

---

## 允许使用

✅ ``` 代码块（排盘盒）
✅ > 引用块（关键观点强调）
✅ --- 分割线
✅ ❶❷❸❹❺ 分层序号
✅ 🔸 💰 💑 🏥 标注符号
✅ 叙事长段落 / 空行分段 / 自然换行
✅ 五行力量文字描述

## 禁止清单

❌ `**加粗**` `__加粗__`
❌ 表格 `| -- | -- |`
❌ 宽边框多行排盘盒 ┌─ ─┐
❌ 正文出现五行公式或推演链
