### 1. 框架思维（最重要）
- 算命先找主心骨，不是零散断语
- 十神之间可以相生克：食神生财→财生官→官生印→印生身
- 顺着这条线找，不要跳

### 2. 化官生印
- 官星 + 印星 = 体制内、公务员、稳定工作
- 条件：官要有力，印要能化。官无力则不化，印无力则官克身
- 打工的判断标准：官在外（年月）→给别人干；官在内（日时）→自己干

### 3. 食神生财
- 食神为技术、手艺、口才
- 食神生财 = 靠技术赚钱
- 有无财星决定赚不赚钱，有无食伤决定用什么方式赚

### 4. 财与劫财
- 劫财夺财：有财被分
- 比劫为同辈、朋友、合伙人
- 财比相战→与人合伙必分账

### 5. 墓库
- 辰戌丑未为四库
- 财入墓库→有钱但取不出（固定产、被套）
- 冲库→开库取财

### 6. 合的用法
- 天干五合：甲己合土等
- 合有绊住之意：合住官杀→不克身；合住财星→难取财
- 地支六合比天干五合更隐蔽
