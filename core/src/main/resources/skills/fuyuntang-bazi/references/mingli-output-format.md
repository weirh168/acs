# mingli-output-format · 输出格式公约

> 钉选·不可删除·不可降级。每次命理分析自动加载。

---

## 推理与表达分离

推理用 pro 深度，一步不跳。午亥暗合、三辰自刑、巳亥冲—推到底。
输出用 flash 式文学化叙事，不列推演链、不说五行公式、用人话讲故事。

---

## 排版铁律

1. 排盘盒用 ``` 代码块，简洁即可
2. 五行力量用文字描述
3. 正文禁止使用 ** 或 __ 加粗符号
4. 段落不限制长度，手机自适应换行
5. 禁止使用表格格式

---

## 允许使用

``` 代码块（排盘盒）
> 引用块（关键观点强调）
--- 分割线
❶❷❸❹❺ 分层序号
🔸 💰 💑 🏥 标注符号
叙事长段落 / 空行分段 / 自然换行
五行力量文字描述

## 禁止清单

❌ **加粗** 或 __加粗__
❌ 表格 | -- | -- | 格式
❌ 宽边框多行排盘盒 ┌─ ─┐
❌ 推演链/五行公式暴露在正文
