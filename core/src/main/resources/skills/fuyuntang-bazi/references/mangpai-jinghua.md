# 盲派精华 · 五大流派集成

## 素水（22讲+迎春+笔记）
- 框架思维：先找主心骨，后看十神链
- 食伤生财/化官生印/食神制杀 三大做功
- 伤官见官：身越旺越严重

## 老人参（四关+十二串宫）
### 通关法
财来坏印 → 首用官杀通关（财→官→印→身），次用比劫克财
七煞月定律 → 七杀必须制化

### 学历
身弱有印＝高学历（未中出印直接生）
身旺有泄＝高学历

### 十二串宫压运断流年
大运+流年+原局 三盘串宫定吉凶

## 段建业（盲派中高级）
### 应期法则
坏掉阻碍的字为应期：什么阻碍了→大运流年去掉它→好事发生
吉凶应期：用神到位则吉，忌神被制则吉

### 天干五合
最高效的做功方式。日主合财→得财，合官→得官

## 清娟/杨氏（六亲专项）
### 财官临墓
财官坐辰戌丑未→需刑冲打开，不开则无用
天干透出+地支有根＝不算入墓
