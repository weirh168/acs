# 命理分析思维框架 · 知识源体系

> ⚠️ 立场声明：AI 命理分析基于海量文本数据的模式识别与语言生成，模拟传统命理师的分析路径，**仅供文化探讨与娱乐参考**，不具备真实的"命运"感知力。

## 一、五大思维模型（分析引擎内核）

### 1️⃣ 整体辩证思维

**原则**：不孤立看任何一个符号。

| 孤立看 | 整体看 |
|--------|--------|
| "你甲木身弱" | "甲木午月火旺木焚——看全局是否有水(印)来生、有土(财)会耗" |
| "你正官被伤官克" | "伤官见官看有无财印通关，有财则官得生，有印则官有救" |

**应用规则**：
- 看日主必看月令（得令/失令）
- 看十神必看组合（是否被合/冲/刑）
- 看格局必看调候（冬夏优先）
- 断吉凶必看全局流通（动态平衡）

### 2️⃣ 取象比类思维

**核心**：将抽象五行干支 → 映射到具体事物。

| 干支 | 自然象 | 人物象 | 身体象 | 性格象 |
|:--:|:--:|:--:|:--:|:--:|
| 甲木 | 参天大树 | 领导者、长辈 | 肝胆、头部 | 正直、刚毅、有担当 |
| 乙木 | 花草藤蔓 | 秘书、中介 | 肩膀、颈椎 | 柔韧、变通、依附 |
| 丙火 | 太阳 | 开拓者 | 心脏、血液 | 热情、光明、急躁 |
| 丁火 | 灯烛星火 | 思考者 | 眼睛、神经 | 细腻、敏锐、多疑 |
| 戊土 | 城墙厚土 | 包容者 | 胃、皮肤 | 厚重、守信、固执 |
| 己土 | 田园软土 | 滋养者 | 脾、肌肉 | 包容、内秀、被动 |
| 庚金 | 刀剑顽金 | 改革者 | 大肠、骨骼 | 果断、锋利、刚烈 |
| 辛金 | 珠宝精细 | 精致者 | 肺、呼吸道 | 精致、讲究、敏感 |
| 壬水 | 江河湖海 | 谋划者 | 膀胱、血液 | 豁达、智慧、漂浮 |
| 癸水 | 雨露甘霖 | 灵性者 | 肾、生殖 | 细腻、灵活、隐秘 |

**应用规则**：
- 十神类象：官=权力/约束，财=金钱/欲望，印=庇护/知识，食伤=才华/表达，比劫=朋友/竞争
- 宫位类象：年=祖上/头部，月=父母/胸部/事业，日=自己/腹部/婚姻，时=子女/下肢/晚年

### 3️⃣ 五行生克制化

**运算逻辑**：

```
相生: 木→火→土→金→水→木（传递能量）
相克: 木→土→水→火→金→木（制约平衡）

制: 强金伐弱木（克之过度）
化: 有火通关 → 金不克木，反成官印相生（转化矛盾）
```

**应用规则**：
- 生不是永远好——生多反为忌（"母慈灭子"）
- 克不是永远坏——克到恰当反为贵（"官杀为用"）
- 通关优先于对抗——见两行相战，先找中间介质

### 4️⃣ 格局与用神

**扫描流程**：

```
1. 判断格局类型
   ├── 正格：正官格、正财格、正印格、食神格…… 
   ├── 偏格：七杀格、偏财格、伤官格、偏印格
   └── 外格：从格(从强/从弱)、化气格、专旺格

2. 锁定用神（使全局趋向平衡的关键五行）
   ├── 扶抑：强者克泄、弱者生扶
   ├── 调候：寒需火暖、燥需水润（优先于扶抑）
   ├── 通关：两行相战时找中介
   └── 病药：有病灶找解药

3. 判断用神得力与否
   ├── 得力：透干+通根+有生源
   ├── 一般：有但不显
   └── 无力：被合/被冲/被克
```

**应用规则**：
- 调候为先 → 扶抑次之 → 通关 → 病药
- 夏生先看水、冬生先看火
- 用神不可破格、忌神不可得势

### 5️⃣ 动态推演（岁运流转）

**三层叠加运算**：

```
原局（命中注定）← 大运（十年趋势）← 流年（当年应期）
```

**应期法则**：

| 信号 | 应事 | 优先级 |
|:--:|:--:|:--:|
| 冲 | 变动/冲突/转折 | ★★★★★ |
| 合 | 合作/缘分/聚合 | ★★★★ |
| 刑 | 纠纷/内耗/病痛 | ★★★ |
| 害 | 暗损/小人 | ★★ |
| 穿 | 意外/突破口 | ★★★ |
| 墓库 | 收藏/积蓄/爆发 | ★★★ |

**应用规则**：
- 天干主事（什么事）、地支主应（何时应）
- 大运前5年看天干、后5年看地支
- 流年合冲原局 → 应期触发

## 三、分析流程速查

```
输入信息
  → bazi.py 排盘（真太阳时）— 排盘结果列在最前
  → 套用五大思维模型
      ① 整体辩证 → 看全局平衡
      ② 取象比类 → 干支十神类象
      ③ 五行生克 → 制化通关
      ④ 格局用神 → 定调+找用神
      ⑤ 岁运流转 → 大运+流年应期
  → 1281例库对照检验
  → 【三段校验】每一处关键年份必须核对：
      ① 该年命主几岁？
      ② 该年龄对应什么人生阶段？
      ③ 该事件是否符合该步大运趋势？
      任一校验不通过则回退重算，校验透明执行不输出
  → 叙事输出（梁秀玉风格模板）
```

## 四、输出模板 · 梁秀玉风格（唯一叙事格式）

### 格式总纲

```
┌─ 标题 ─────────────────────────────┐
│  性格/人生特征分析 — 八字四柱       │
│  乾造/坤造 | 出生年 | 当前大运       │
└────────────────────────────────────┘

一、五行性格总览
  [表格：五行 | 力量 | 性格表现 | 影响 | 🔴/⚠️ 标记]

二、分层拆解（4层，从内核到外围）
  第一层：日主 — 骨子里的底色
    - 日主五行类象（如庚金=刀剑顽铁）
    - 得时与否（月令+全局）
    - 具体性格表现
    - 反推验证：绑定真实生活事件 ✓
  
  第二层：核心矛盾 — 命局最大的张力
    - 官杀混杂/伤官见官/财印交战等
    - 具体表现（行为模式、选择困境）
    - 反推验证：对应真实人生阶段 ✓
  
  第三层：月令十神 — 人际/事业风格
    - 透干十神对社交/职场的影响
    - 对钱财/朋友的态度
  
  第四层：时柱/藏干 — 情绪处理模式
    - 隐藏的情感模式
    - 压力应对方式
    - 反推验证：对应真实生活事件 ✓

三、性格优缺点
  优点：3-5条 + 缺点：3-5条

四、一句话总结
  有画面感、有共情的人话。
  不用套话，直击命主内心。
```

### 写作守则

| 规则 | 说明 |
|:----|:-----|
| 语言 | 口语化但不油滑，像老师在跟学生讲 |
| 深度 | 每层必须绑定真实生活事件，拒绝空洞描述 |
| 标记 | 🔴=核心驱动力  ⚠️=辅助/隐患 |
| 验证 | 从已知事件反推命局逻辑，让分析有"对了"的感觉 |
| 收尾 | 一句扎心但温暖的话结尾，不说"仅供参考" |
| 禁用 | 不带免责声明、不模棱两可、不说"可能""也许" |

### 示例节选

```
🔴 第一层：庚金日主 — 骨子里的底色
庚金是刀剑、顽铁——刚强、讲义气、不服输。
吃软不吃硬，遇强更强。
但庚金生于卯月，春季的金不得时令：
表面刚强，内心有软处。
硬撑的时候多，真正需要帮助不会开口。
从已验证事件看：20岁谈恋爱分手，是子午冲直接冲击夫宫。
这个冲不是小事——她心里那道疤，几十年都没完全过去。
```
