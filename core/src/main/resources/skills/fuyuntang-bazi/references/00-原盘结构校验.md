# 00-原盘结构校验 · 硬性防错

> 钉选·不可跳过。凡是要写「大运」「流年」「某年会发生什么」之前，先跑这一步。
> 起因：曾把大运戊戌里的「戌」当成原局地支，写出「戌冲辰」「未戌相刑」——辰、未根本不在原局，整段判断因此作废。

---

## 一、三层各锁各的

```
原局 = 年支 月支 日支 时支        只有这四个，别的一个都不许有
大运 = 一个天干 + 一个地支        只有这两个字
流年 = 一个天干 + 一个地支        只有这两个字
```

拿 乙丑 乙酉 乙丑 壬午 举例：

```
原局四支：丑 酉 丑 午           ← 合法集合只有这 4 个
大运戊戌：戊 戌                 ← 戌是运，不是原局
流年丙午：丙 午                 ← 午既在原局也在流年，要按层说清
```

禁止把三层的支混成一个池子。任何「X冲Y」「X刑Y」先问：这两支是不是同一层？不是就必须标成「大运×原局」或「流年×原局」。

---

## 二、执行顺序（不许颠倒）

❶ 锁原局：写下四支，形成合法集合。
❷ 列原局内部结构：只在四支之间找刑冲合破害、半合、三合、三会、伏吟、自刑。这一步的结论与岁运无关。
❸ 锁大运：只取运的干支。
❹ 列大运与原局的关系：每条都要写成「大运X与某支Y…」，不得写成「原局X…」。
❺ 锁流年：只取年的干支。
❻ 列流年与原局、与运的关系：同样按跨层写。
❼ 断语前先出两张清单：成立 / 不成立，再动笔。

---

## 三、机器检查（先跑再写）

```
run_bundled_script  source=skills/fuyuntang-bazi  script=scripts/fuyuntang.py
args=["check","--bazi","乙丑 乙酉 乙丑 壬午","--dayun","戊戌","--liunian","丙午"]
```

返回里有：原局四支、锁定集合、层内结构、大运与原局、流年与原局、禁止项。

写完断语再回审一遍：

```
args=["check","--bazi","…","--dayun","戊戌","--liunian","丙午","--text","你写的整段话"]
```

「违例」非空就是串盘：那段里出现了不属于任何一层的地支，必须重写。

---

## 四、断语模板（照这个句式写就不会串）

```
原局：酉丑半合金局，丑午相害，年日丑伏吟——这是本盘自带的底色。
大运戊戌：运支戌与年支丑、日支丑相刑，与月支酉相害，与时支午半合火——运带来的压力与转机。
流年丙午：流年午与年支丑、日支丑相害，与时支午自刑——今年的触发点。
```

反过来，这些都是错的：

```
✗ 原局戌冲辰          ← 原局没有戌，也没有辰
✗ 未戌相刑，主胃病      ← 未不在任何一层
✗ 大运辰戌冲，原局受冲   ← 若原局无辰，这句话把运支当原局用了
```

---

## 五、成立 / 不成立清单（断语前必填）

```
成立：
  - 原局酉丑半合金局（年丑、日丑、月酉三支俱在）
  - 大运戌与丑相刑（运支与原局年支、日支）
流年触发：
  - 流年午与时支午自刑（同盘自刑，需看午在原局与流年同时出现）
不成立：
  - 戌冲辰：辰不在原局，也不在运年
  - 未戌相刑：未不在原局，也不在运年
```

一条不成立，就不许写进断语，更不能拿它推病、推财、推婚。

---

## 六、和别的规则的关系

本源规则优先于叙事规则：`mingli-life-narrative` 要求「实证反推」，但被反推的那句话本身必须先通过本源校验。

- 排盘错了 → 全错，回去跑 `paipan`。
- 结构串了 → 断语作废，回去跑 `check`。
- 只有两者都过，才允许写流年/大运的具体事件。

---

## 七、自查三问

❶ 我写的每个地支，能在「原局 / 大运 / 流年」三层里指出它属于哪一层吗？
❷ 每个刑冲合破害，两个支在同一层吗？跨层的有没有标「大运×原局」？
❸ 断语有没有依赖一个不成立的机制？有一条就整段重写。
