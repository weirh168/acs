# 01-宫位引动校验 · 硬性防错

> 钉选·不可跳过。写「某年会发生某事」之前，先跑这一层。
> 与 00-原盘结构校验 分工：00 管「地支属于哪一层」，01 管「事件落在哪一宫」。

---

## 一、四柱即四宫

```
年柱  祖业 / 父母 / 童年
月柱  事业 / 兄弟 / 青年
日柱  婚姻 / 自身 / 中年
时柱  子女 / 晚年 / 下属
```

某一年真要「有事」，一定是某柱被引动了——要么被运冲合，要么被年冲合刑害，要么伏吟自刑。**没被引动的柱，不许多安事件。**

---

## 二、引动方式与强度（冲最重，伏吟最轻）

```
冲 5 ＞ 三合/半合/三会/六合 4 ＞ 刑/自刑 3 ＞ 害/破 2 ＞ 伏吟 1
```

同一个柱被两处同时引动，按强度排序，先写重的。

---

## 三、机器检查

```
args=["check","--bazi","乙丑 乙酉 乙丑 壬午","--dayun","戊戌","--liunian","丙午","--layer","gongwei"]
```

以阿柱盘为例的实测结果：

```
年丑  刑（大运戌）、害（流年午）      祖业/父母/童年
月酉  害（大运戌）                    事业/兄弟/青年
日丑  刑（大运戌）、害（流年午）      婚姻/自身/中年
时午  半合火局（大运戌）、自刑（流年午） 子女/晚年/下属
无引动柱：无
```

看这张表就知道：这一年四宫全动，但「月柱只被害、不冲」——写「月柱被冲」就是错的。

写完回审：

```
args=["check","--bazi","…","--dayun","戊戌","--liunian","丙午","--layer","gongwei","--text","你写的断语"]
```

「违例」非空就是乱断：要么声称的方式与实算不符（如把害写成冲），要么给一个根本没被引动的柱安了事。

---

## 四、正确与错误句式

```
✓ 日支被大运刑、被流年害——婚姻宫今年双重受动，主关系里的磨。
✓ 时支被流年自刑、与大运半合火——晚年宫/子女宫的事，自己的心结为主。
✗ 月柱被冲——月支酉与大运戌是害不是冲。
✗ 年柱被冲、主搬迁——年支丑今年只被刑，没有被冲。
✗ 今年四柱皆动，事事不顺——四宫全动不等于全凶，得逐宫看方式与喜忌。
```

---

## 五、断语模板

```
今年落在日宫：日支丑被大运戌刑、被流年午害，婚姻与自身这条线是主战场。
今年落在月宫：月支酉只被大运戌害，事业宫受影响但轻，别写成大变。
没有引动的柱：无——所以今年是「多点同时动」的年份，不是「一件事定全年」。
```

---

## 六、和别的规则的关系

- 先过 00-原盘结构校验（地支属于哪一层），再过本源校验（事件落在哪一宫），最后才允许写叙事。
- 事件必须挂到柱上，且方式要与实算一致；跨两柱时按「日 > 月 > 时 > 年」排主次。
- 若同一柱同时被刑被害，写「刑为主、害为辅」，不要含糊成「被冲」。

---

## 七、自查三问

❶ 我写的每个「某年如何」，都点名了是哪一柱吗？
❷ 我写的方式（冲/合/刑/害/伏吟）与 check 给的实算一致吗？
❸ 有没有给「无引动柱」硬安事件？有就删掉重写。
