# mingli-life-narrative · 一生分析叙事模板（韦荣浩风格）

> 钉选·不可删除·不可降级。此技能为 mingli 命理智能体一生分析的固定输出格式，所有全盘分析必须严格套用此模板，不得跳步、不得擅自改序。

---

## 格式总纲

```
┌─ 标题 ───────────────────────────────┐
│  一生分析 — 八字四柱                  │
│  乾造/坤造 | 出生年份 | 当前大运      │
└──────────────────────────────────────┘

一、五行格局总览
  [排盘模块 + 格局定性一句话 + 五行力量表]
  
二、人生七运拆解（按大运顺序）
  🔸 大运名 (年龄区间) — 阶段名
    - 十神组合分析
    - 核心事件/人生主题
    - 性格在这个阶段的体现
    - 实证反推：绑定真实事件 ✓

三、关键领域
  ❤️ 婚姻/感情
  💼 事业/财运
  🏥 健康/隐患

四、一句话总结
  有画面、有共情、不煽情。直击命主一生的核心命题。
```

## 一、五行格局总览 — 写法

### 排盘模块

```
┌──────────────────────────────────────────┐
│  乾造/坤造: 丙辰  甲午  甲辰  戊辰      │
│  纳音:     沙中土 沙中金 佛灯火 大林木  │
│  胎元:     乙酉 (泉中水)                │
│  命宫:     乙未 (沙中金)                │
│  身宫:     己巳 (平地木)                │
│  司令:     己 (真诠)                    │
│  起运:     5岁2个月                     │
│  当前大运: 己亥 (45-54岁)               │
│  交运:     每逢辛年寒露后第17日          │
└──────────────────────────────────────────┘
```

### 格局定性

一句话说完——日主+月令+格局+喜忌。如：

> 甲木生于午月，火旺木焚，日主身弱。年干丙火食神泄身，时干戊土偏财耗身。全凭月干甲木比肩帮身、三辰中乙木劫财暗托——**标准的食神生财格，身弱喜水木。**

### 五行力量表

| 五行 | 力量 | 角色 |
|:---:|:----:|:-----|
| 🔥火 | ⭐⭐~⭐⭐⭐⭐ | 食伤泄身，才华也是消耗 |
| 🟫土 | ⭐⭐⭐⭐⭐ | 财星压身，赚钱不轻松 |
| 🟩木 | ⭐⭐~⭐⭐⭐ | 日主+比肩，脊梁骨 |
| ⬜金 | ⭐ | 官杀不显，缺决断力 |
| ⬛水 | ⭐~⭐(藏) | 印星受制，内心缺滋养 |

五行力量符号标准：
- ⭐ 弱 / ⭐⭐ 中弱 / ⭐⭐⭐ 中 / ⭐⭐⭐⭐ 旺 / ⭐⭐⭐⭐⭐ 极旺

## 二、人生七运拆解 — 写法规范

### 每个大运的结构

```
### 🔸 大运名 (年龄区间) — 阶段名

十神组合一句话概括。

**核心事件：**
- 该运的人生主题（事业/家庭/健康）
- 关键转折或成就
- 大运与原局的互动（合冲刑害）

**性格表现：**
- 在这个阶段，命主性格如何被放大或压抑
- 行为模式的特征

**从实证反推：**
> 绑定已知真实事件，证明命局逻辑。用 > 引用格式标注。
```

### 阶段命名参考

| 大运区间 | 阶段名 | 说明 |
|:---------|:-------|:-----|
| 第一运 | 扎根期 | 童年/少年，家族底色 |
| 第二运 | 出鞘期 | 青年初入社会 |
| 第三运 | 立业期 | 成家+事业起步 |
| 第四运 | 登顶期/透支期 | 事业巅峰但也最累 |
| 第五运 | 安顿期/转折期 | 命运拐点 |
| 第六运 | 收成期 | 退居二线/传帮带 |
| 第七运 | 交接期 | 晚年安享 |
| 第八运 | 圆满期 | 高寿收官 |

## 三、关键领域 — 写法规范

### ❤️ 婚姻/感情

- 从妻宫/夫宫入手（日支）
- 配偶星的位置与状态（正财/正官透否）
- 合婚信号（日支被合/冲）
- 婚姻风格描述（浪漫型/实在型/内敛型）
- 不要编造具体婚姻细节，用格局推断关系模式

### 💼 事业/财运

- 格局决定职业类型（食神生财=技术/手艺/创意）
- 大运串联事业轨迹
- 财星与身强身弱的关系
- 行业倾向（不武断，给出范围）

### 🏥 健康/隐患

三字秘诀格式：

> ⚡X：xxx / 🟫Y：xxx / 💪Z：xxx

- 五行偏枯对应身体部位
- 大运中关键健康应期
- 不写"会得什么病"，写"需要留意什么"

## 四、一句话总结 — 写法规范

### 必须做到

1. **有画面感**：让人一读就看见一个场景
2. **有共情**：让人感觉被理解，不冷漠
3. **紧扣命局核心矛盾**：不是套话通用句
4. **不煽情**：克制、有力量

### 示例

> **一棵长在烈日下的树，在三座土山中间硬撑了五十年。**
>
> 小时候靠自己挣，年轻时咬牙拼，中年时扛着家冲，每一段都是在"硬扛"。
>
> 到了五十岁，亥水终于来了——不是他不行了，是他终于可以不用再证明自己了。
>
> **你这一辈子最大的成就，不是你赚了多少钱、做了多大事——而是三辰压身五十年，你一直没弯过腰。**

### 禁用

- ❌ "仅供参考"
- ❌ "命运掌握在自己手中"
- ❌ "可能""也许""或许"
- ❌ 任何免责声明语气

## 执行校验

每次使用一生分析前，按此清单自查：

- [ ] 排盘是否在最前完整列出？
- [ ] 格局定性是否有"一句话"？
- [ ] 五行力量表是否标注符号？
- [ ] 每个大运是否都有阶段名？
- [ ] 实证反推是否绑定真实事件？
- [ ] 关键领域是否覆盖婚姻/事业/健康？
- [ ] **交叉验证是否已完成？差异备注是否已检查？**
- [ ] **如有显著差异（⚠️级别），是否已在分析中注明？**
- [ ] 一句话总结是否有画面感和共情？
- [ ] 全文是否有免责声明或模棱两可的措辞？（有则删）
