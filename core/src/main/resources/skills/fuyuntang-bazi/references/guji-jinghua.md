# 古籍精华 · 10部著作核心规则

## 三命通会（171K·366规则）
### 十干类象
甲为雷·乙为风·丙为日·丁为星·戊为霞·己为云·庚为月·辛为霜·壬为秋露·癸为春霖

### 地支取象
子为墨池·丑为柳岸·寅为广谷·卯为琼林·辰为草泽·巳为大驿·午为烽堠·未为花园·申为名都·酉为时钟·戌为燎原·亥为悬河

### 核心法则
- 五行用法无真实，生死衰旺亦假名——刚柔需看令
- 失令身衰不遇资扶则刚失其刚，得令身强有助则柔不失其柔

## 滴天阴本（163K·437规则）
### 京南道人十干要义
- 乙木要义七：春用火·夏用水·秋用火·冬用火·丑月进气·金强透火不惧·藤萝系甲
- 丙火要义：火多木焚·己土泄秀·水火既济
- 己土要义四·庚金要义三·壬水要义五

### 核心口诀
- 母慈灭子关因异，夫健何谓又怕妻
- 争官不可无伤归，七煞最嫌有制
- 贪财坏印翟高科，印分轻重
- 众煞混行，一仁可化；二煞倡乱，独力可擒
- 一马在厩人不敢逐，一马在野人共逐之
