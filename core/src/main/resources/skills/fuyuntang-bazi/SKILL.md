## 容易出错的地方
- 串盘是最容易犯的错：把大运地支当原局地支写「戌冲辰」「未戌相刑」，而原局根本没有辰、未。写前先跑 check。
- 年柱看立春不看元旦：2/4 前出生仍是上一年。
- 性别决定大运顺逆：阳男阴女顺、阴男阳女逆，填反整个大运十年全错。
- 真太阳时别乱传：不知道经度就别传；东经 105° 以西的 12 点会退到巳时，要提示用户重排。
- 时辰不确定就问，不要猜；猜错时柱整盘废。
- 引擎「年龄推算」的起运与排盘差约 3 年，报告换运年份以排盘为准。
- 输出禁止 ** 加粗、禁止表格；排盘用 ``` 代码块，可用 > 引用、--- 分隔、❶❷❸、🔸💰💑🏥。
- 婚姻次数按财官个数断（素水口径），不按穿害断；别自己改口径。
- 一次别取全量：--modules all 的输出有几十 KB，模型容易陷入读写文件循环；要全看就分 2-3 次取单模块（core / health / marriage+career）。
- 命理是传统读法：不做疾病诊断、不做投资承诺、不吓人；涉医疗法律财务让用户找专业人士。

## 怎样算办成
- 排盘四柱、起运、顺逆、八步大运齐全，与出生信息对得上；
- 判读给出格局评分与品级，且至少引一条规则结论，不是即兴发挥；
- 输出符合公约：无加粗、无表格、排盘盒用代码块；
- 问具体问题（婚姻/事业/健康/某年）时，落到具体年份或具体事项。

## 什么时候停下交给用户
- 出生时间只知大概（如下午、傍晚）→ 先要几点几分与出生地，别猜。
- 要求断生死、疾病确诊、彩票股票买卖点 → 拒绝，只谈倾向与传统解读。
- 要求改命、化解、做法事、买开运物 → 说明本技能只做分析，不提供。
- 引擎报错或缺数据 → 原样回传报错，不许用常识补一个盘。
